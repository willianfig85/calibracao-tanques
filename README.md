# Calibração de Tanques

Aplicação web simples para calibração e simulação de tanques cilíndricos.

## Arquivos principais

- `index.html` — aplicação
- `manifest.json` — configuração PWA
- `service-worker.js` — funcionamento offline básico
- `icons/` — ícones do aplicativo

## Publicar no GitHub Pages

1. Crie um novo repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`.
6. Salve.

O GitHub fornecerá o endereço público do aplicativo.

## Instalar no celular

Depois de publicar, abra o endereço pelo navegador do celular e escolha:

- Android/Chrome: **Instalar aplicativo** ou **Adicionar à tela inicial**.
- iPhone/Safari: **Compartilhar → Adicionar à Tela de Início**.
